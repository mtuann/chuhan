Sao lưu dữ liệu

Bản sao lưu gồm toàn bộ dữ liệu trên máy này: từ đã đánh dấu và câu gặp từ, chữ đã tập viết, lượt gõ và kỷ lục, ghi nhớ của bạn, cài đặt. File được nén gzip (.json.gz), giữ lại để chuyển sang máy khác.

Xuất dữ liệu

Tải toàn bộ dữ liệu xuống thành một file .json.gz.

Nhập dữ liệu

Chọn file sao lưu (.json.gz, hoặc .json cũ) đã xuất trước đó. Mặc định app gộp dữ liệu của file vào máy này, không xoá gì: dùng được để khôi phục, hoặc để gom dữ liệu từ hai máy.

So sánh máy này với file

Máy nàyFile

Gộp: thêm từ đã đánh dấu, lượt tập viết, lượt gõ… của file mà máy chưa có; giữ cài đặt và các ghi nhớ mới hơn của máy này. Nhập cùng một file hai lần không sinh dữ liệu trùng.

Thay thế toàn bộ dữ liệu trên máy bằng file

Mọi dữ liệu trên máy này sẽ bị xoá và thay bằng dữ liệu của file. Trước khi thay, app tự tải xuống một bản sao lưu của máy này để bạn lấy lại được.
